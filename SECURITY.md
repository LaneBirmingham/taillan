# Security

TailLAN opens network tunnels between players' computers, so security reports are very welcome.

Please report vulnerabilities privately through GitHub's **Report a vulnerability** button (Security tab), not in public issues. Include what an attacker needs (an invite code? the same LAN? a malicious website?) and what they can reach.

In scope, for example: reaching ports or hosts beyond a game's declared ports, joining without the invite code, a kicked player getting back in, other devices reaching a joiner's forwarded ports, websites driving the local UI, or crashing a host or joiner with crafted traffic or invites.

Weaknesses in tailcat or Tailscale's relays themselves belong upstream: https://github.com/tailscale/tailcat/security.
